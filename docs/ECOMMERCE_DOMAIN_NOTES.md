## 1. 商品详情页结构(PDP - Product Detail Page)

**定义**:用户在电商平台点击商品后看到的页面,包含促成下单转化的全部信息。

**7 大核心要素**:

| 要素 | 作用 | 采集难度 |
|------|------|----------|
| **商品标题** | 搜索引擎/平台搜索权重核心,30 字以内最佳 | ⭐ 易 |
| **主图 + 视频** | 第一印象,影响点击率 → 转化率 | ⭐⭐ 中 |
| **SKU 选择** | 规格/颜色/尺码组合,直接关联客单价 | ⭐⭐ 中 |
| **价格** | 划线价/促销价/会员价等多档展示 | ⭐⭐ 中(需多源对比) |
| **销量 + 评价数** | 社会证明,影响新客决策 | ⭐⭐ 中 |
| **评价内容** | 差评关键词决定迭代方向 | ⭐⭐⭐ 难(需登录/反爬) |
| **店铺信息** | DSR/粉丝/品牌资质 | ⭐ 易 |

**业务洞察**:标题与主图是"搜索 → 点击"的关键,价格与评价是"点击 → 转化"的关键。**竞品监控必须同时抓这两段**。

## 2. 平台流量分发逻辑

不同平台的算法逻辑差异巨大,影响"爆款打造策略"。

### 淘宝 / 天猫
- **核心逻辑**:搜索权重 = 关键词权重 × 人群标签 × 店铺权重
- **关键因子**:坑产(UV 价值)、DSR、好评率、回购率
- **流量来源**:搜索(50%+) + 推荐(30%+) + 付费(10%~20%)

### 京东
- **核心逻辑**:搜索权重 + 品牌权重 + 自营标记
- **关键因子**:入仓率、京东物流占比、Plus 会员价
- **流量来源**:搜索(60%+) + 大促会场(20%+) + 推荐(10%)

### 拼多多
- **核心逻辑**:裂变 + 性价比 + 活动
- **关键因子**:百亿补贴、拼团率、复购率
- **流量来源**:推荐(50%+) + 拼多多 APP 入口 + 微信裂变

### 抖音电商
- **核心逻辑**:推荐算法 = 标签 × 完播率 × 互动率
- **关键因子**:短视频/直播内容质量、达人合作、千川投流
- **流量来源**:推荐 Feed(70%+) + 直播 + 商城搜索

**业务洞察**:**同一商品在不同平台的爆款逻辑不同**。竞品监控需分平台运营策略输出。

## 3. 价格矩阵(Price Matrix)

**定义**:同一商品在不同时间/不同用户视角下呈现的多种价格。

| 价格类型 | 说明 | 竞品监控价值 |
|----------|------|--------------|
| **划线价** | 原价/原价虚高(常见) | 判断"促销力度" |
| **日常价** | 长期稳定售价 | 基础对比锚点 |
| **大促价** | 双 11/618 期间 | 大促节奏关键 |
| **会员价** | Plus/88VIP 专属 | 用户分层运营 |
| **新人价** | 首单优惠 | 拉新成本评估 |
| **拼购价** | 拼多多/百亿补贴 | 跨平台价格战 |
| **淘金币/京豆价** | 平台积分抵扣 | 实际成交价估算 |

**业务洞察**:**仅抓"展示价"会严重失真**,竞品周报必须呈现价格矩阵而非单点价格。

## 4. SKU 策略

**定义**:同一商品通过规格/颜色/尺码等维度拆分的多个最小销售单元。

### SKU 三层架构
1. **引流 SKU**:低价款,目的拉点击(常见亏本)
2. **爆款 SKU**:主力销量款,利润主要来源
3. **长尾 SKU**:高利润款,贡献客单价

### SKU 监控 4 大指标
- **SKU 数量**:总规格数(影响搜索覆盖)
- **爆款 SKU 占比**:Top 1 SKU 销量占比(健康度)
- **库存状态**:是否有断色断码(影响转化)
- **价格梯度**:相邻 SKU 价差(影响连带率)

**业务洞察**:**SKU 1 涨价、SKU 2 降价、SKU 3 重新组合**是竞品常见的"调价不调价"动作,需结构化记录。

## 5. 评价分析(Review Mining)

**定义**:从用户评价中提取情感、痛点、改进建议的文本分析。

### 评价类型分级
| 层级 | 内容 | 监控价值 |
|------|------|----------|
| **L1 评分** | 1~5 星 | 整体满意度,周报必备 |
| **L2 文本** | 用户文字评价 | 痛点/卖点挖掘 |
| **L3 追评** | 收货后 N 天追加 | 真实使用反馈 |
| **L4 买家秀** | 图片/视频 | 视觉一致性 |
| **L5 商家回复** | 客服响应 | 售后服务评估 |

### 差评关键词分类(实战)
- **质量类**:做工、材质、用一段时间坏了(40%+)
- **物流类**:发货慢、破损、快递员态度(20%+)
- **客服类**:响应慢、推诿、不解决(15%+)
- **描述类**:与详情页不符(15%+)
- **价格类**:买贵了、降价快(10%)

**业务洞察**:**差评关键词 = 迭代路线图**。竞品差评的高频词往往是本品的差异化机会。

## 6. 营销节点(Marketing Calendar)

**定义**:电商行业周期性的大促/活动节奏。

### 年度关键节点
| 节点 | 平台 | 力度 | 备战期 |
|------|------|------|--------|
| **年货节** | 全平台 | ⭐⭐⭐ | 提前 30 天 |
| **38 女王节** | 淘宝/京东 | ⭐⭐ | 提前 14 天 |
| **618** | 京东主场 | ⭐⭐⭐⭐⭐ | 提前 45 天 |
| **818** | 京东/苏宁 | ⭐⭐⭐ | 提前 21 天 |
| **双 11** | 淘宝主场 | ⭐⭐⭐⭐⭐ | 提前 60 天 |
| **双 12** | 淘宝 | ⭐⭐⭐ | 提前 21 天 |
| **年货节(年底)** | 全平台 | ⭐⭐⭐ | 提前 30 天 |

### 日常活动
- **百亿补贴**:拼多多日常(每周更新)
- **天天特卖**:淘宝(每日 9 场)
- **京东秒杀**:每日 N 场
- **抖音超级品鉴**:每周 1~2 次

**业务洞察**:**大促前 7 天的价格/库存/活动动作是核心情报**。EcomRadar 的"竞品周报"应在大促前 3 天开始加密抓取频率。

## 7. 店铺健康度(Store Health)

**定义**:综合评估店铺信誉、运营能力、服务质量的多维指标体系。

### 核心指标
| 指标 | 含义 | 健康阈值 |
|------|------|----------|
| **DSR 描述相符** | 商品与描述一致性 | ≥ 4.8 |
| **DSR 服务态度** | 客服响应/解决率 | ≥ 4.8 |
| **DSR 物流服务** | 发货速度/快递质量 | ≥ 4.8 |
| **店铺等级** | 心/钻/冠/金冠 | 金冠/皇冠 |
| **粉丝数** | 店铺关注用户 | 行业 Top 30% 以上 |
| **开店时长** | 信誉积累 | ≥ 1 年 |
| **违规记录** | 平台处罚次数 | 0 |
| **退换货率** | 售后服务压力 | < 5% |

### 旗舰店 vs 专营店 vs 普通店
- **旗舰店**:品牌方直营,信任度最高
- **专卖店**:品牌授权,单品牌经营
- **专营店**:多品牌经营,SKU 多但信任度次之

**业务洞察**:**竞品店铺健康度 = 其抗风险能力**。在"价格战"中,健康度低的店铺更容易被拖垮,这是动态竞争的判断依据。

## 给 Writer 的 Prompt 锚点

后续 Writer 节点生成竞品报告时,必须强制覆盖以下结构:

1. **Executive Summary**:3~5 句,涵盖最大价格波动 / 新品动作 / 评价异动
2. **竞品对比表**:Markdown 表格,字段含 价格 / 销量 / DSR / 策略
3. **价格波动分析**:对比上周 / 上月,标注涨/降/促销节点
4. **SKU 动态**:新增/下架/库存变化
5. **评价洞察**:差评 TOP3 + 好评 TOP3
6. **行动建议**:基于以上事实给出 3~5 条可执行建议
