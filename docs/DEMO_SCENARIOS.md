## 场景 1:智能音箱品类周报(京东 + 淘宝)

### 业务背景
**客户角色**:某新锐智能音箱品牌"声立方"的市场负责人
**监控对象**:天猫精灵 / 小度 / 小爱同学 / HomePod(3~5 个 SKU)
**使用频率**:每周一上午 9 点
**决策依据**:本周是否调整价格 / 是否加码投放 / 是否有竞品新动作

### 输入
```json
{
  "platforms": ["jd", "tmall"],
  "category": "智能音箱",
  "product_urls": [
    "https://item.jd.com/100012345678.html",
    "https://item.jd.com/100023456789.html",
    "https://item.jd.com/100034567890.html",
    "https://detail.tmall.com/item.htm?id=123456789",
    "https://detail.tmall.com/item.htm?id=234567890"
  ]
}
```

### 预期输出(报告样例)

```markdown
# 竞品周报 - 智能音箱品类(2026-W42)

## Executive Summary
本周天猫精灵下调主力款售价 12%(从 ¥299 → ¥263),小度新增
"户外便携"SKU 抢占细分市场,小爱同学差评率上升 3pp(主要集中
在"蓝牙连接不稳定")。建议声立方本周内做"音质升级"内容营销
,与天猫精灵的价格战形成错位。

## 竞品矩阵对比

| 品牌    | 价格    | 销量    | DSR  | 评价数 | 关键动作         |
|---------|---------|---------|------|--------|------------------|
| 天猫精灵| ¥263 ↓  | 8w+     | 4.9  | 12w+   | 大促降价 + 满减  |
| 小度    | ¥329    | 5w+     | 4.8  | 8w+    | 新增户外 SKU     |
| 小爱同学| ¥349    | 3w+     | 4.6  | 6w+    | 联名款 + 礼盒    |
| HomePod | ¥2,299  | 5k+     | 4.9  | 1.2w   | 维持高端定位     |

## 价格波动分析
- **天猫精灵**:主力款 ¥299 → ¥263(-12%),触发"百亿补贴"标签
- **小度**:稳定 ¥329,新增 SKU ¥499(户外便携)
- **小爱同学**:稳定 ¥349,联名礼盒 ¥399(+14%)

## 评价洞察
### 差评 TOP3
1. 蓝牙连接不稳定(38%) - 主要影响小爱同学
2. 音质平庸(22%) - 全品类通病
3. 售后响应慢(15%) - 主要影响小度

### 好评 TOP3
1. 性价比高(45%) - 主要影响天猫精灵/小度
2. 智能联动方便(28%) - 全品类
3. 外观设计好(18%) - HomePod 领跑

## SKU 动态
- 新增:小度"户外便携版" ¥499
- 下架:小爱同学"经典款" 清仓完毕
- 库存告急:HomePod 白色款

## 行动建议
1. **错位定价**:声立方可在 ¥299~¥399 价格带做"音质升级"差异化
2. **内容种草**:抖音/小红书打"蓝牙连接稳定性"实测内容,直击小爱软肋
3. **SKU 策略**:考虑新增 ¥499 户外便携 SKU,跟随小度布局
4. **大促预案**:天猫精灵 12% 降价可能在双 11 加大力度,提前 30 天备货
5. **客服投入**:小度差评中"售后响应"占比 15%,可作为对比营销点
```

### 业务价值
- ✅ 节省 4~6 小时/周的人工比价时间
- ✅ 价格异动早于平台官方公告 1~2 天
- ✅ 差评关键词实时捕捉,反馈到产品迭代

## 场景 2:美妆口红赛道月报(淘宝 + 抖音)

### 业务背景
**客户角色**:某新锐国货美妆品牌"慕斯"的内容运营
**监控对象**:完美日记 / 花西子 / 珂拉琪 / 3CE / YSL(5 个品牌,各 2~3 个爆款 SKU)
**使用频率**:每月 1 号
**决策依据**:月度营销节奏 / 新品跟进 / 达人投放方向

### 输入
```json
{
  "platforms": ["tmall", "douyin"],
  "category": "口红",
  "brand_filter": ["完美日记", "花西子", "珂拉琪", "3CE", "YSL"],
  "time_range": "monthly"
}
```

### 预期输出(报告样例)

```markdown

9 月口红赛道整体销售额同比上升 18%,完美日记"动物眼影盘"联名

人投放(合作达人 +45%)。YSL 维持高端定价但销量稳定。

|-----------|-----------|-------|---------|------|-----------------|

| YSL       | 纯口红    | ¥320  | 3w+     | 4.9  | 品牌护城河      |

## 价格矩阵(9 月)

| 品牌      | 日常价 | 会员价 | 大促价 | 实际成交价(估算) |
|-----------|--------|--------|--------|-------------------|
| 完美日记  | ¥129   | ¥109   | ¥89    | ¥95~¥115         |
| 花西子    | ¥219   | ¥199   | ¥179   | ¥185~¥210        |
| 珂拉琪    | ¥69    | ¥59    | ¥49    | ¥55~¥65          |

## 评价洞察
### 差评 TOP3
1. 颜色与图片不符(32%) - 完美日记/珂拉琪
2. 拔干(28%) - 哑光类通病
3. 包装廉价(15%) - 主打性价比品牌

1. 显白(38%)

- **珂拉琪**:拼多多百亿补贴专享(9 月常驻)
- **3CE**:小红书 KOC 投放 +45%(9 月)
- **YSL**:维持高端,无明显促销

## 行动建议
1. **跟进联名**:慕斯可考虑与热门 IP 联名(国潮/动漫/明星)
2. **达人矩阵**:小红书 KOC + 抖音中腰部达人,3:7 投入比例
3. **价格锚定**:国货新锐建议 ¥89~¥129 价格带,与 YSL 形成对比
4. **色彩故事**:主打"显白""持久"两大卖点
5. **大促备战**:双 11 提前 45 天备货(参考完美日记动作)
```

### 业务价值
- ✅ 月度营销节奏可视化,辅助慕斯排期
- ✅ 价格带分析,辅助新品定价
- ✅ 达人投放方向对标,避免盲目投流

## 场景 3:3C 数码小品类日榜单(拼多多 + 抖音)

### 业务背景
**客户角色**:某拼多多头部 3C 卖家的运营
**监控对象**:手机壳 / 钢化膜 / 充电线(每个品类 Top 50 SKU)
**使用频率**:每日 8 点
**决策依据**:日榜数据,选品 + 定价 + 跟款决策

### 输入
```json
{
  "platforms": ["pdd", "douyin"],
  "categories": ["手机壳", "钢化膜", "充电线"],
  "top_n": 50,
  "frequency": "daily"
}
```

### 预期输出(报告样例)


### 业务价值
- ✅ 日榜实时监控,跟款时效从"3 天发现"缩短到"1 小时"
- ✅ 价格分布可视化,辅助选品定位
- ✅ 平台对比,辅助多平台运营策略

## 演示路径

3 个场景构成由浅入深的演示链:

1. **场景 3(日榜)**:展示"实时性"和"高频监控"能力
2. **场景 1(周报)**:展示"结构化分析"和"价格矩阵"
3. **场景 2(月报)**:展示"趋势研判"和"营销建议"

面试演示时,建议先讲场景 1(最典型),再补充场景 2/3 体现业务广度。
